# Crave — Online Food Ordering System

A simple responsive food-ordering website built with HTML, Tailwind CSS and JavaScript. Users can browse dishes, search and filter the menu, add items to a cart, update quantities, view the bill and place a simulated order.

## Objectives

- Build a user-friendly food menu.
- Demonstrate JavaScript DOM manipulation and event handling.
- Implement cart and checkout functionality.
- Demonstrate collaborative development using Git and GitHub.
